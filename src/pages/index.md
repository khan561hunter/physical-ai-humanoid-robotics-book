# Physical AI & Humanoid Robotics: Embodied Intelligence in the Real World

Welcome to the comprehensive guide on Physical AI and Humanoid Robotics. This book takes you on a hands-on journey through the exciting world of embodied intelligence, where artificial intelligence meets the physical world through robotics.

## What You'll Learn

This book covers the complete spectrum of building intelligent humanoid robots:

- **ROS 2 Fundamentals**: Master the Robot Operating System 2, the backbone of modern robotics
- **Digital Twin Simulation**: Create and control virtual robots in Gazebo and Unity
- **AI-Powered Perception**: Integrate NVIDIA Isaac Sim for advanced computer vision and navigation
- **Vision-Language-Action (VLA)**: Build robots that understand and act on natural language commands
- **Capstone Project**: Implement a complete voice-controlled object manipulation system

## Learning Path

The book follows a structured, hands-on approach with four progressive user stories:

1. **ROS 2 Basic Joint Control** - Understand fundamentals through simple joint manipulation
2. **Humanoid Navigation in Simulation** - Simulate robot navigation with obstacle avoidance
3. **AI-Robot Brain Training** - Train locomotion policies using reinforcement learning
4. **Voice-Controlled Object Manipulation** - Capstone project integrating all concepts

## Hardware Options

We provide guidance for three hardware configurations:

- **Digital Twin Workstation**: High-performance setup for simulation and training
- **Physical AI Edge Kit**: Deploy AI models on NVIDIA Jetson for real robots
- **Cloud Robotics Lab**: Scalable cloud-based development with Ether Lab
